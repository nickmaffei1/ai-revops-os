Re-pull every number before it reaches a colleague. If it cannot be verified in time, say so and delay rather than send an unverified figure.

**Why:** a count carried over from last week's report went into a leadership update and was off by a definition change made in between.

**How to apply:** write a receipt for each number (value, display form, source, query, time). The number-receipt hook blocks drafts with unreceipted numbers.
