Outward-facing messages are always drafts. The operator sends.

**Why:** a broad go-ahead ("ship it all") once got read as approval to send a colleague-facing reply that had only been staged. Sends cannot be undone.

**How to apply:**
- Chat: use the draft tool only. Tickets and email: show the exact text in chat.
- No exception for send-sounding verbs. Draft it, say where the draft is, and stop.
- Shipping work (data pulls, PRs, merges) follows its own approval rules and is separate from this.
